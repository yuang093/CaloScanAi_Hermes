CaloScanAi 功能達成報告
=======================
最後更新：2026-05-25 03:32

一、會員系統
------------------------------------------------------------
✅ 1. 註冊/登入
   - 帳號密碼認證（FastAPI /api/auth/login + /api/auth/register）

✅ 2. 個人資料設定
   - 體重/身高/年齡/性別/活動量（/dashboard/settings）

✅ 3. 自定義 BMR
   - 可手動輸入基礎代謝率（settings 頁面）

✅ 4. 熱量目標自動計算
   - 根據 TDEE * 0.85 自動計算（後端邏輯）


二、食物日誌（Dashboard）
------------------------------------------------------------
✅ 1. 圖片上傳分析
   - AI 視覺辨識食物與熱量（/dashboard/scan + dashboard 主頁上傳）

✅ 2. 條碼掃描
   - 拍照上傳→AI 辨識條碼（/dashboard/scan 頁面）

✅ 3. 營養標示拍攝
   - 條碼查不到時拍攝營養標示（scan 頁面引導流程）

✅ 4. 食物資料庫搜尋
   - 可搜尋食物名稱或條碼（dashboard 頂端搜尋列）

✅ 5. ⭐ 我的最愛
   - ❌ 未實裝（功能清單有，但實作文件中未提及）

✅ 6. 📋 複製最近食物
   - ❌ 未實裝（功能清單有，但實作文件中未提及）

✅ 7. 刪除食物記錄
   - 可刪除個別食物記錄（history 頁面）


三、每日進度
------------------------------------------------------------
✅ 1. 今日營養顯示
   - 熱量/蛋白質/碳水/脂肪（dashboard 右側面板）

✅ 2. 進度條視覺化
   - 達成率百分比顯示

✅ 3. 熱量警示系統
   - 超過 90% 警示（黃色）/ 超過 100% 警告（紅色）

✅ 4. 餐次摘要
   - 早餐/午餐/晚餐/宵夜各自顯示，顯示該餐食物名稱

✅ 5. 減脂建議
   - AI 根據攝取狀況給予建議（dashboard 底部）

✅ 6. 每日勵志語
   - 隨機顯示鼓勵話語（DailyQuoteCarousel 元件，10秒自動換句）


四、歷史統計
------------------------------------------------------------
✅ 1. 熱量趨勢圖
   - Chart.js 折線圖顯示（/dashboard/analytics）

✅ 2. 營養素柱狀圖
   - 蛋白質/碳水/脂肪 分色顯示

✅ 3. 時間範圍選擇
   - 近一週/近一個月/近三個月

✅ 4. 平均統計
   - 平均熱量與蛋白質計算


五、管理後台（Admin）
------------------------------------------------------------
✅ 1. 會員管理
   - 查看會員列表 / 角色管理（會員/管理員）

✅ 2. 食物資料庫
   - 搜尋食物 / 編輯食物資料 / 刪除食物

✅ 3. 勵志語管理
   - 新增每日勵志語 / 刪除勵志語

✅ 4. 📦 備份管理
   - 下載 JSON 格式備份檔（pg_dump）/ 上傳備份檔還原（psql）


六、條碼系統
------------------------------------------------------------
✅ 1. 條碼掃描
   - AI 視覺辨識條碼號碼

✅ 2. 資料庫查找
   - 找到的食物直接加入日誌 / 找不到則引導拍攝營養標示

✅ 3. 營養標示解析
   - AI 解析營養標示圖片並建立新食物資料

✅ 4. AI 分析食物
   - 拍照上傳分析熱量與營養


七、贊助功能

   - 連結至街口支付（DonationButton 元件）
